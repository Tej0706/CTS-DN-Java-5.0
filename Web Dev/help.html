How to Use the Portal

Welcome to the Local Community Event Portal help page. Follow these steps to use the portal easily.

  1. Browse upcoming events in the Events section.
  2. Use category filters and search to find events.
  3. Fill the registration form carefully.
  4. Watch event videos and explore gallery images.
  5. Use "Find Nearby Events" for location support.
